# Client Configuration Checklist

Request these items from the client before moving beyond Phase 1 mock mode:

- Client GitHub repository.
- Deployment branch.
- Deployment owner.
- Databricks App access.
- Approved model or agent backend type.
- Endpoint or resource identifier.
- Permission for the App identity to invoke the approved resource.
- Groups that should use the App.
- Future source-storage option.
- Future project-record storage option.

Do not request anything from the colleague who performed the independent
feasibility test.
