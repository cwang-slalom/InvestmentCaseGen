# Writing Style Guide

Write for sophisticated donors, investors, and funding partners.

## Principles

- Lead with the concept and the change capital can enable.
- Be concrete about the problem, population, geography, and intervention.
- Use persuasive framing without exaggeration.
- Prefer evidence-backed specificity over broad claims.
- Separate sourced facts from generated narrative framing.
- Name uncertainty directly.

## Avoid

- Generic fundraising language.
- Claims that any organization should receive funds without evidence.
- Unsupported cost, scale, timeline, partner, or impact claims.
- Copying language from reference examples.
